# Internal Sources for Module 3

This file records the accuracy posture behind Module 3.

## Claim

Before using AI on workplace material, learners should decide what information the task actually requires and reduce unnecessary exposure.

## Learner Move

Classify information sensitivity, remove or abstract unnecessary details, separate routine theme analysis from urgent or policy-sensitive follow-up, and check whether the tool and context are approved for the data involved.

## Source Anchors

- NIST Privacy Framework is a voluntary tool for identifying and managing privacy risk while protecting individuals' privacy.
  - https://www.nist.gov/privacy-framework
- NIST AI RMF 1.0 frames AI risk management around context, trustworthiness, governance, and impacts to people and organizations.
  - https://www.nist.gov/publications/artificial-intelligence-risk-management-framework-ai-rmf-10
- NIST AI RMF Generative AI Profile is a cross-sectoral companion resource for generative AI risk management.
  - https://www.nist.gov/publications/artificial-intelligence-risk-management-framework-generative-artificial-intelligence

## Caveat

The module does not provide legal advice and does not claim that specific data categories always have the same legal status. The public version teaches general minimization and boundary-setting habits using synthetic examples.

## Scenario Accuracy

The activity uses synthetic messages. The recommended classifications are based only on the information supplied in the activity and the stated learning goal: theme analysis with reduced data exposure.
