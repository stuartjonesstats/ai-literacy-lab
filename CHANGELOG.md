# Changelog

## 1.0.0 - 2026-05-13

- Published the first stable public release of AI Literacy Lab.
- Finalized the sequenced eight-part learner path: seven modules plus capstone.
- Added lightweight pause prompts to selected modules to support judgment
  without adding extra gates.
- Tightened local completion gates while preserving learner judgment and
  avoiding keyword-hunting.
- Added facilitator guidance, regulated-setting adoption notes, and team-use
  guidance.
- Updated GitHub Pages workflow actions and confirmed production deployment.
- Clarified the project scope: ad hoc professional learning, workshop pre-work,
  and supplemental training rather than certification, LMS replacement, or
  compliance evidence.

## 0.2.0-prototype - 2026-05-10

- Added eight-module interactive site structure with capstone simulation.
- Added pre-reflection and post-reflection bookends.
- Added local progress, ordered module path, and browser-based learning record.
- Added source notes across modules.
- Added organizational adoption guidance and public team-use page.
- Strengthened local-storage fallback behavior and reset confirmation.

## 0.1.0-concept

- Established curriculum map, competency map, learning design notes, and initial
  module drafts.
