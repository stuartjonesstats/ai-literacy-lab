## Learning Goal

Use AI in everyday work through a responsible workflow rather than a one-shot
prompt-and-trust pattern.

<WorkflowBuilderLab client:load />

## Signature Activity

Workflow redesign: learners improve an AI-assisted process that is initially too
vague, too trusting, or poorly reviewed.

## Productive Struggle

The initial workflow should be attractive because it saves time, but fragile
because it lacks purpose, constraints, verification, or ownership.

## Debrief

AI can be very useful in everyday work when the learner separates the work into
stages.

Better pattern:

```text
1. Define the purpose.
2. Remove or abstract sensitive information.
3. Ask AI to organize, question, or draft a bounded piece.
4. Inspect the output for unsupported claims and missing context.
5. Verify facts that matter.
6. Revise in your own judgment.
7. Document assumptions or open questions.
```

## Practice Task

Redesign the one-shot prompt into a staged workflow.

Example:

```text
First, organize these sanitized notes into themes. Do not add facts.
Second, list open questions separately from conclusions.
Third, draft a briefing note using only the provided notes.
Finally, mark any claims that need human verification before the meeting.
```

## Self-Check Rubric

- Emerging: writes a better prompt but still treats AI as the final author.
- Developing: adds constraints and asks for uncertainty.
- Proficient: separates organizing, drafting, verification, and final judgment.
- Advanced: includes data minimization, open questions, and documentation of assumptions.

## Transfer Principle

Use AI as part of a workflow: define the purpose, constrain the task, inspect
the output, verify what matters, and own the final work.

## Grounding

This module connects individual AI use to management-system thinking: define
the work, control inputs, review outputs, and preserve accountable ownership.
