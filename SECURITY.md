# Security and Privacy

The public AI Literacy Lab site is designed as a static, no-login learning
experience.

## Public Site Data Handling

- No learner account is required.
- No backend database is required.
- No analytics are enabled by default.
- Learner responses, progress, reflections, and the learning record stay in the
  browser when local storage is available.
- If local storage is blocked, the site falls back to less persistent browser
  storage or in-memory session state.

## Reporting Issues

Report security, privacy, or data-handling concerns through the project issue
tracker once the public repository is available. Avoid posting real learner
data, confidential workplace examples, credentials, or private records in a
public issue.

## Out of Scope

The public site does not provide identity verification, proctoring, auditable
enterprise completion tracking, or policy enforcement. Organizations needing
those controls should add them through their own systems rather than silently
modifying the public learner experience.
