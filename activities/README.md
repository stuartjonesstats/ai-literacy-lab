# Activities

Activities are reusable pieces that can appear inside modules, workshops, or self-guided learning paths.

## Activity Types

- Scenario cards
- Decision exercises
- Verification challenges
- Risk reclassification tasks
- Data boundary tests
- Bias lens shifts
- Human review challenges
- Escalation forks
- Reflection prompts

## Design Rule

Every activity should require a learner to do something with judgment:

- classify
- compare
- verify
- revise
- explain
- document
- escalate
- redesign

Avoid activities whose only purpose is to check whether the learner read a definition.
