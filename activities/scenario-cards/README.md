# Scenario Cards

Scenario cards are short, realistic situations that can be used for warmups, discussions, or module openings.

## Card Format

- Title:
- Context:
- Decision:
- Hidden complication:
- Target misconception:
- Transfer principle:
- Suggested debrief:

## Example

### The Polished Summary

Context: A coworker uses AI to summarize a long policy document before a meeting.

Decision: Would you rely on the summary to answer questions in the meeting?

Hidden complication: The summary omits an exception that applies to a small but important group of cases.

Target misconception: If a summary sounds clear and complete, it is safe to rely on.

Transfer principle: Compression can hide exceptions, uncertainty, and minority cases.

Suggested debrief: Ask what kind of document requires source checking and what parts of a summary deserve verification.
