# Module 3: Data, Privacy, and Confidentiality

## Durable Question

What should not be entered, shared, or inferred?

## Learning Goal

Learners will classify information sensitivity and choose safer ways to use AI without exposing inappropriate data.

## Signature Activity

Data boundary test: learners inspect realistic workplace material and decide what can be shared, what must be redacted, what should be abstracted, and what should not be used.

## Productive Struggle

The scenario should include mixed-sensitivity information so that "never use AI" and "just paste it in" both feel too simplistic.

## Transfer Principle

Before using AI, ask what data is being exposed, whether the tool is approved for that exposure, and whether the task can be redesigned with less sensitive input.
