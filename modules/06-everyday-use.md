# Module 6: Using AI Well in Everyday Work

## Durable Question

How can AI improve work without replacing judgment?

## Learning Goal

Learners will design responsible AI-assisted workflows for common tasks such as drafting, summarizing, planning, brainstorming, critiquing, and organizing information.

## Signature Activity

Workflow redesign: learners improve an AI-assisted process that is initially too vague, too trusting, or poorly reviewed.

## Productive Struggle

The initial workflow should be attractive because it saves time, but fragile because it lacks purpose, constraints, verification, or ownership.

## Transfer Principle

Use AI as part of a workflow: define the purpose, constrain the task, inspect the output, verify what matters, and own the final work.
